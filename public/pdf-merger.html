Merge only the pages you need

Add multiple PDFs, review page thumbnails, select individual pages, reorder pages across source documents, rotate pages, or mark pages for removal. The page summary shows the exact selected count before export.

Large-file progress

Loading and exporting update after each real page operation. There is no simulated timer. Browser memory remains the practical limit, so very large document sets may require smaller batches.

Private browser processing

PDF bytes stay in this browser. Pinned PDF.js and pdf-lib application code is downloaded only when this tool is used; no conversion API receives the document.

Honest limitations

Source annotations are preserved with copied pages. Reliable annotation flattening and bookmark-tree preservation are not enabled because the browser library does not safely expose those operations for every PDF.

How to merge PDFs

  1. Add PDFs with the picker or drag and drop.
  2. Select, rotate, delete and drag pages into the final order.
  3. Set optional title, author, subject, keywords and filename.
  4. Merge and download the generated PDF.
Are PDFs uploaded?

No. Documents remain local during normal processing.

Can encrypted PDFs be merged?

Password-protected or encrypted PDFs may be rejected. The tool shows an error instead of creating a misleading output.
