Resize images precisely

Choose exact dimensions, percentage scaling or a scale factor. Preserve the original aspect ratio, fit an image inside a canvas, fill and crop to exact dimensions, or intentionally stretch it when required.

Social media presets

Use prepared sizes for Instagram square, portrait and Story images, YouTube thumbnails, LinkedIn posts, X posts and Facebook posts. Presets only change dimensions; you remain in control of crop and output settings.

Supported input

JPG/JPEG, PNG, WebP, GIF first frame and AVIF when the browser can decode it. EXIF orientation is applied during browser decoding where supported.

Output and privacy

Export PNG, JPG or WebP. AVIF appears only when the active browser proves it can encode AVIF. Canvas re-encoding removes embedded metadata; transparent content can stay transparent or be flattened onto a chosen background.

Performance limits

Processing runs in a dedicated Web Worker with a 120-megapixel output safety limit. Very large, malformed or unsupported images receive a visible error instead of a fake result. Worker termination, bitmap closure and object-URL revocation release temporary resources.

Browser encoder limitations

Progressive JPEG and arbitrary DPI/PPI metadata are not exposed by standard Canvas encoders, so this tool does not claim those capabilities.

How to resize an image

  1. Add one or more images by file picker, drag and drop, or clipboard paste.
  2. Select an image, choose dimensions or a social preset, and set fit, crop, rotation and output options.
  3. Run the real processing queue. Review before/after dimensions and file sizes.
  4. Select a processed image and click Download to save it directly. Each queued image also has its own Download button.

Image Resizer FAQ

Are my images uploaded?

No. User-selected image bytes are decoded and re-encoded in the browser. Normal website assets still use ordinary network requests.

Why is GIF output not available?

The first GIF frame can be resized, but standard browser Canvas APIs do not reliably encode animated GIF output. Choose PNG, JPG, WebP or supported AVIF instead.

Can resizing make a file larger?

Yes. Dimensions, output format, transparency and quality all affect size. The result panel reports both reductions and increases honestly.
